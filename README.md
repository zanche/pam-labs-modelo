# pam-labs

Repositório de trabalho da disciplina **Programação para Aprendizagem de Máquina** (Especialização em Ciência de Dados, CIn-UFPE).

## Se você chegou pelo modelo

Este é o repositório-modelo da disciplina. Para criar o seu:

1. Clique em **Use this template** e depois em **Create a new repository**.
2. Dê o nome **pam-labs** e marque **Private**.
3. No seu repositório novo, abra **Settings › Collaborators › Add people** e convide o professor: **zanche**.
4. Clone o repositório no seu computador e siga os slides de Git e GitHub.

Depois disso, apague esta seção e escreva abaixo o que o seu repositório contém.

## O que vai aqui

Ao longo da disciplina, este repositório recebe o seu projeto: o ambiente com uv, o pacote com as suas funções, o script de treino, os testes e a aplicação. As aulas e as listas ficam em [zanche/pam-material](https://github.com/zanche/pam-material).

## O que não vai para o Git

O `.gitignore` deste modelo já deixa de fora dados, modelos treinados, o ambiente virtual (`.venv/`) e o arquivo de segredos (`.env`). Não remova essas linhas.

## Como instalar e rodar

_Preencha quando o projeto tiver um `pyproject.toml`: os comandos para instalar o ambiente e rodar os testes._
